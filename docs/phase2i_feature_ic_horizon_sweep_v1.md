## Method

For each of the 13 point-in-time features, and each forward horizon
**h ∈ {5, 10, 21, 63}** sessions, we measure the per-date cross-sectional
**Spearman rank IC** between the feature value on `as_of_date` and the
`h`-session forward **excess return vs SPY** (name forward return minus SPY
forward return over the same window). Spearman is computed as Pearson on ranks
(the GCP venv has no scipy).

**Label sourcing.** The official **5d** label is the scored CSV's own
point-in-time column `realized_excess_return_5d_vs_spy` — we do not recompute it
— while the **10/21/63d** labels are derived from `phase2g_price_history_real.csv`
(forward `adj_close` ratio minus SPY's). As a provenance check the analyzer also
computes a price-derived 5d excess and reports its correlation against the scored
5d column.

For audit clarity the diagnostics JSON records this provenance explicitly at the
top level:

- `label_sources` — a per-horizon map declaring exactly where each label comes
  from: `"5": "scored_csv.realized_excess_return_5d_vs_spy"` and
  `"10" / "21" / "63": "price_history.forward_excess_return_vs_spy"`.
- `label_cross_checks.5d_scored_vs_price_derived` — the structured 5d
  scored-vs-price-derived check: `correlation` (1.0), `n` (rows compared),
  `mean_abs_diff`, and `max_abs_diff`.

The legacy `label_5d_cross_check` block is retained for backward compatibility.

For each feature×horizon cell we report:

- `mean_rank_ic`, `std_rank_ic`, and the **information ratio** = mean / std of
  the per-date IC series;
- `n_dates`, `n_rows`, and a `low_confidence` flag (true when `n_dates` falls
  below `min_dates = 120` — the **63d sample guard**, which flags rather than
  silently drops thin cells);
- `direction` (bullish/bearish), pooled quintile-spread `top_minus_bottom_spread`,
  `quintile_monotonic`, `top_decile_hit_rate`;
- per-year and per-quarter rank IC, plus `years_matching_sign` /
  `year_sign_consistent` (sign agrees with the overall sign in ≥ `year_sign_min`
  = 3 of 4 years).

**KEEP/DROP rule (locked).** A feature is **KEEP** only if, at its best horizon
(the confident cell with the largest `|mean_rank_ic|`): the magnitude clears the
floor `|mean_rank_ic| ≥ 0.03`, **and** the IC sign is consistent in ≥ 3 of 4
years, **and** that best horizon is not `low_confidence`. Survivors are then
**ranked by `|information ratio|`**.

## What this means (read honestly)

**The only features with measurable edge are a volatility / beta / correlation
tilt at the quarterly (63d) horizon — not stock-picking alpha.** Five of the six
KEEP features are risk measures (`realized_vol_21d`, `rolling_beta_63d`,
`downside_vol_21d`, `realized_vol_63d`, `rolling_corr_spy_63d`), and all carry a
**positive** sign: over 2023–2026, the higher-volatility, higher-beta,
higher-SPY-correlation names in this mega-cap universe earned higher 63d forward
excess returns. That is a **risk-on / high-beta tilt across a strong bull run**,
it is regime-dependent, and it would be expected to **invert in a drawdown**. It
is not a demonstrated, market-neutral edge.

Three further cautions:

1. **Edge concentrates almost entirely at 63d.** At 5/10/21d every feature
   (including the KEEP set, where the shorter horizons mostly miss the floor)
   is weak; the signal only emerges at the quarterly horizon, where overlapping
   forward windows make per-date observations highly autocorrelated, so the
   effective sample is far smaller than the 539–762 raw dates suggest.
2. **No cell is cleanly monotonic.** `quintile_monotonic` is false for nearly
   every KEEP cell and top-decile hit rates sit near `0.50` (max `~0.55` for
   `momentum_12_1` at 63d). The edge is a weak rank *tilt*, not an ordered
   score→return gradient.
3. **Every raw return feature and both SPY-excess return features are at
   noise** at every confident horizon (`|IC| < 0.03`) — momentum-as-raw-return
   does not rank this universe; only the `momentum_12_1` (12-1) construction
   clears the floor, and only at 63d.

## Recommended next experiments (research only — none enabled, deployed, or traded)

1. **Beta / vol neutralize, then re-measure.** Because the KEEP set is dominated
   by vol/beta/correlation, neutralize the forward excess return against beta and
   realized vol and re-run this sweep to test whether **any residual,
   market-neutral** ranking signal survives. If it does not, the "edge" is purely
   a risk premium and must not be promoted as alpha.
2. **Walk-forward validation at 63d with overlap-aware errors.** Re-estimate the
   63d IC out-of-sample with non-overlapping or block-bootstrapped windows so the
   information ratios are not inflated by overlapping labels.
3. **Build a vol/beta-tilt-aware composite candidate.** If a neutralized signal
   survives, fit a small cross-sectional weighting on the KEEP set
   (`momentum_12_1` plus the neutralized risk features), validated walk-forward,
   rather than the equal-weight mean-z composite that failed in 2G-C.
4. **Wire the legacy comparison.** As in 2H-A, capture the existing production
   prediction series over the same window and compute its 63d rank IC head-to-head
   before any `GO_CANDIDATE`.

## Conclusion

A single-feature sweep does find non-trivial cross-sectional ranking signal — but
it is a **63d volatility / beta / correlation tilt**, positive across a 2023–2026
bull run, regime-dependent, and not a clean monotonic gradient. The raw-return and
SPY-excess-return features are at noise. There is no demonstrated, market-neutral
**production edge** here; the honest read is that before any rebuild the KEEP set
must be beta/vol-neutralized and validated walk-forward to see whether anything
survives once the risk-premium tilt is removed.
